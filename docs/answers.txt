4. Mention two reasons why branches are used in a Git repository.

Branches let developers work on separate features or fixes without
immediately changing the main branch. They also let developers test
and review changes before merging them into the main branch.

5. What is the difference between git log and git status?

git log displays committed history, including commit messages,
authors, and dates. git status shows the current working tree and
staging area, including modified, staged, and untracked files.

6. What command shows commits where Vehicle.h was one of the
committed files?

This shows the file's commit history and follows it across renames.

8. In object-oriented programming, what are inheritance,
polymorphism, and encapsulation?

I. Inheritance allows a derived class to build on a base class,
reusing accessible data and behavior.

II. Polymorphism allows the same interface to produce different
behavior depending on the object's type. For example, derived
classes can provide different implementations of a virtual method.

III. Encapsulation groups data and methods inside a class and
controls access to the object's internal state through an interface.

9. What is the main difference between the Dictator and Lieutenants
workflow and the Integration Manager workflow?

The Integration Manager workflow places integration and conflict
resolution under one manager. The Dictator and Lieutenants workflow
adds another layer: lieutenants integrate changes for groups of
developers and resolve conflicts. The dictator then integrates the
lieutenants' changes and is the only person who pushes to the
central, or blessed, repository.

10. How would a team of 100 developers benefit from the Dictator
and Lieutenants workflow instead of the Centralized workflow?

Lieutenants can review changes and resolve conflicts for smaller
groups in parallel. This distributes the integration workload and
reduces the coordination required among developers pushing to one
shared repository. The dictator can focus on combining the
lieutenants' reviewed changes into the official project.
